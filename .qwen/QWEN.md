# SmartWord Project Rules

## 🔴 CRITICAL — Обязательно к исполнению

### Git операции
- **ЗАПРЕЩЕНО трогать Git** — никогда не делать `git commit`, `git push`, `git pull` или любые другие git команды
- Git полностью под контролем пользователя

### Минимизация подтверждений
- **Стараться не спрашивать** о подтверждении удаления файлов/папок
- Если действие очевидно из контекста — выполнять сразу
- Спрашивать только если удаление критичное или неоднозначное

### Процессы и сервер
- **НЕЛЬЗЯ убивать ВСЕ  node.js процессы** (`taskkill /IM node.exe /F`)
- **Использовать targeted kill** — убивать только процессы конкретного проекта (по порту или пути)
- Пример безопасного завершения: `netstat -ano | find ":3000"` → найти PID → `taskkill /PID <id>`

### Логирование и отладка
- **Всегда проверять логи** перед внесением изменений
- Если ошибка — **сначала прочитать лог**, потом предлагать решение
- Не делать предположений без данных из логов

### Тестирование
- **Всегда тестировать** изменения перед тем как сказать "готово"
- Для Telegram бота — **проверять с реальным пользователем**
- Не говорить "работает" пока пользователь не подтвердит


## 🚫 Запрещено

- ❌ Убивать процессы без спроса
- ❌ Говорить "готово" без тестирования
- ❌ Игнорировать логи ошибок
- ❌ Писать код без обработки ошибок
- ❌ Делать сложные решения когда есть простые

---

## ✅ Поощряется

- ✅ Спрашивать если не уверен
- ✅ Предлагать несколько вариантов решения
- ✅ Писать понятный и чистый код
- ✅ Документировать сложные моменты
- ✅ Думать о UX пользователя

---

## 📞 Связь с пользователем

- Если проблема не ясна — **задать уточняющие вопросы**
- Если решение не работает — **предложить альтернативу**
- Если нужна информация — **сказать что именно нужно**
- Не пропадать — **держать в курсе прогресса**
