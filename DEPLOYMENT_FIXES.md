# Исправление проблем с регистрацией и входом

## Проблемы, которые были исправлены

### 1. ❌ Вечная загрузка при запросах
**Причина:** Отсутствие таймаутов на API запросах

**Исправление:**
- Добавлен таймаут 15 секунд для всех запросов
- Добавлена обработка `AbortError` с понятным сообщением
- Файл: `client/src/lib/api.ts`

### 2. ❌ Письма с подтверждением не приходят
**Причина:** SMTP не настроен

**Исправление:**
- Улучшено логирование отправки писем
- При отсутствии SMTP используется Ethereal (тестовый ящик)
- Ссылка на письмо появляется в логах сервера
- Файлы: `server/src/email/send.js`, `server/src/modules/auth/auth.routes.js`

### 3. ❌ Непонятные ошибки при регистрации
**Причина:** Недостаточное логирование и обработка ошибок

**Исправление:**
- Добавлено подробное логирование на каждом шаге регистрации
- Улучшены сообщения об ошибках (таймаут, 502, 503, сеть)
- Файл: `client/src/screens/Auth/SignInScreen.tsx`

### 4. ❌ Ошибки на английском языке
**Причина:** В исходном коде некоторые ошибки были на английском

**Исправление:**
- Все сообщения об ошибках переведены на русский
- Файлы: `client/src/lib/api.ts`, `client/src/hooks/useWords.ts`, `client/src/hooks/useGroups.ts`, `client/src/contexts/AuthContext.tsx`

## Что нужно сделать для продакшена

### Шаг 1: Настроить сервер

```bash
cd /home/davchick/Desktop/SmartWord/server
```

1. **Сгенерировать секреты:**
```bash
# JWT Secret
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

# JWT Refresh Secret
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

2. **Отредактировать `.env`:**
```bash
nano .env
```

Обязательные поля:
- `DATABASE_URL` — ваш PostgreSQL
- `JWT_SECRET` — минимум 32 символа
- `JWT_REFRESH_SECRET` — минимум 32 символа
- `OPENROUTER_API_KEYS` — ключи для AI чата
- `SMTP_*` — для отправки писем (см. SMTP_SETUP.md)

3. **Установить зависимости:**
```bash
npm install
```

4. **Запустить миграции:**
```bash
npx prisma migrate deploy
npx prisma generate
```

5. **Запустить сервер:**
```bash
npm run dev
```

### Шаг 2: Настроить клиент

1. **Отредактировать `.env`:**
```bash
cd /home/davchick/Desktop/SmartWord/client
nano .env
```

Проверьте:
- `EXPO_PUBLIC_API_URL=https://api.smart-word.ru`

2. **Установить зависимости:**
```bash
npm install
```

3. **Запустить:**
```bash
npm start
```

### Шаг 3: Проверить работу

1. **Зарегистрироваться в приложении**

2. **Проверить логи сервера:**
   - Должны быть сообщения:
     ```
     [auth/register] Attempting registration for email: ...
     [auth/register] User created: ...
     [email] Sending email to ...
     [email] Message sent: ...
     ```

3. **Если SMTP не настроен:**
   - Найдите в логах ссылку Ethereal:
     ```
     === ETHEREAL LINK FOR ...: https://ethereal.email/message/xxx ===
     ```
   - Откройте ссылку в браузере
   - Кликните "Confirm my account"

4. **Войти с подтверждённым аккаунтом**

## Проверка таймаутов

Теперь при проблемах с сетью вы увидите:
- `"Превышено время ожидания ответа от сервера"` — через 15 секунд
- `"Сервер временно недоступен"` — при 502 ошибке
- `"Сервер перегружен"` — при 503 ошибке

## Дополнительные улучшения

### 1. Мониторинг сервера

Добавьте логирование в production:
```bash
# Установите pm2
npm install -g pm2

# Запустите с pm2
pm2 start server/src/server.js --name smartword-api

# Просмотр логов
pm2 logs smartword-api
```

### 2. HTTPS для продакшена

Убедитесь, что ваш сервер доступен по HTTPS:
- Используйте nginx как reverse proxy
- Получите SSL сертификат через Let's Encrypt

### 3. Резервное копирование БД

Настройте регулярные бэкапы PostgreSQL.
