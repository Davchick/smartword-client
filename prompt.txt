ПРОМПТ ДЛЯ СОЗДАНИЯ МОБИЛЬНОГО ПРИЛОЖЕНИЯ-СЛОВАРЯ (REACT NATIVE + SUPABASE)

1. ОБЩЕЕ ОПИСАНИЕ ПРОЕКТА

Название: SmartWord

Цель: Создать мобильное приложение для iOS и Android (кроссплатформенно) на React Native, которое помогает пользователям учить иностранные слова. Основные функции:

· Пользователь создаёт языковые группы (например, "Английский", "Арабский (фусха)") и добавляет в них слова с переводом.

· Приложение хранит слова на сервере, привязывая их к аккаунту пользователя (регистрация по email/паролю).

· Есть тренировка в формате свайпов: показывается слово, пользователь свайпает вправо (знаю) или влево (не знаю). Результаты влияют на частоту появления слов: при правильном ответе увеличиваем счётчик correct_count, при неправильном — уменьшаем (но не ниже 0). При каждой тренировке слова сортируются так, чтобы сначала показывались те, у которых correct_count меньше и last_reviewed раньше (простейший алгоритм интервальных повторений).

· Встроенный AI-чат-бот, который задаёт вопросы на изучаемом языке, используя слова из словаря пользователя, и проверяет ответы пользователя. Бесплатно даётся 2 сообщения, далее требуется Premium.

· Монетизация через in-app purchases: Premium-подписка (месяц/год) или разовая покупка "навсегда". Premium снимает лимиты на количество групп и слов, а также даёт безлимитный AI-чат.

Целевая аудитория: Пользователи из СНГ (Россия, страны ближнего зарубежья). Это важно для выбора AI-провайдера , хостинга  и платёжных методов.

Технологический стек:

· Фронтенд: React Native (с использованием Expo для скорости разработки).

· Бэкенд: Supabase  — авторизация по email/паролю, база данных PostgreSQL, Edge Functions для AI-чата.

· Монетизация: In-app purchases (expo-in-app-purchases или react-native-iap).

Бизнес:

Приложение создаётся с единственной целью — максимизировать прибыль. Монетизация строится по модели Freemium с жёсткими лимитами:

- Бесплатный тариф: не более 3 групп, не более 30 слов всего, 6 сообщения в AI-чате.

- Premium (подписка или разовая покупка): безлимитные группы и слова, безлимитный AI-чат, приоритетные функции в будущем.

Цены (ориентир): 299₽/мес, 1990₽/год, 3990₽ навсегда.

Воронка продаж:

- При попытке превысить лимит — красивое модальное окно с предложением Premium.

- AI-чат: 6 бесплатных сообщения, затем блокировка с предложением подписки.

- Push-уведомления для возврата и напоминания о лимитах.

Ретенция: ежедневные тренировки, стрик (серия дней), умный AI-чат, напоминания о забытых словах.

Закон 20/80:

Первая версия (релиз через 2-3 недели) должна содержать только критически важные функции:

1. Регистрация/логин (email/пароль).

2. Создание групп и добавление слов (с лимитами).

3. Тренировка-свайп с описанной логикой.

4. AI-чат ( с 6 бесплатными сообщениями).

5. In-app покупка Premium (разблокировка лимитов и AI).

Что НЕ делаем в первой версии: редактирование слов (только удаление/добавление), поиск, офлайн, сложные алгоритмы повторений, социальные функции, локализация интерфейса (только русский).

2. UI/UX: ОЧЕНЬ ВАЖНО! ДИЗАЙН ДОЛЖЕН БЫТЬ ДОРОГИМ И СОВРЕМЕННЫМ

Требования к интерфейсу:

- Использовать современную дизайн-систему (например, Radix UI или Shadcn, адаптированную под React Native). Можно взять React Native Paper и кастомизировать.

- Цветовая палитра: минимализм, светлая тема с мягкими тенями, акцентный цвет (например, спокойный синий или зелёный). Тёмная тема опционально.
- Типографика: крупные, чёткие шрифты (Inter, SF Pro, Roboto). Все размеры и отступы выдержаны в единой сетке.

- Анимации: плавные переходы, микро-анимации нажатий, свайп карточек с эффектом пружины (React Native Reanimated 3). Тактильный отклик (haptic) на свайпы.

- Иконки: минималистичные векторные (Feather, Lucide).

- Экран тренировки: карточка слова с тенью, скруглёнными углами, крупным текстом. При свайпе карточка улетает с анимацией, появляется следующая.

- AI-чат: пузырьки, аватар бота, индикатор набора. Сообщения бота могут быть с иконкой "AI".

- Никакой лишней графики, много пустого пространства (white space) — признак дорогого дизайна.

Все компоненты должны быть переиспользуемы, тема вынесена в отдельный файл. Обязательно протестировать на разных разрешениях.
