# Настройка SMTP для SmartWord

Подробный гайд по переменным окружения и настройке реальной отправки писем (верификация email, сброс пароля).

---

## Переменные окружения — что куда и зачем

Все переменные прописываются в `server/.env`.

### SMTP_HOST
**Что это:** Адрес почтового сервера, через который отправляются письма.

**Зачем:** Приложение не отправляет письма само — оно подключается к SMTP‑серверу провайдера почты (Яндекс, Mail.ru, Gmail и т.п.), который уже доставляет письма получателям.

**Примеры:**
- Яндекс: `smtp.yandex.ru`
- Mail.ru: `smtp.mail.ru`
- Gmail: `smtp.gmail.com`
- Yandex для домена: `smtp.yandex.ru` (тот же)

---

### SMTP_PORT
**Что это:** Порт подключения к SMTP‑серверу.

**Зачем:** Разные порты означают разные способы шифрования:
- **587** — STARTTLS (соединение сначала обычное, потом шифруется). Обычно `SMTP_SECURE=false`.
- **465** — SSL/TLS сразу. Обычно `SMTP_SECURE=true`.
- **25** — без шифрования, часто блокируется провайдерами.

**Рекомендация:** Для Яндекс и Mail.ru — порт **465** с `SMTP_SECURE=true`.

---

### SMTP_SECURE
**Что это:** Использовать ли шифрование SSL/TLS сразу при подключении.

**Зачем:** Без шифрования пароль и содержимое писем идут по сети в открытом виде. `true` — безопасное подключение (порт 465). `false` — порт 587, шифрование включается через STARTTLS.

**Значения:** `true` или `false` (строка в .env).

---

### SMTP_USER
**Что это:** Логин для входа на SMTP‑сервер.

**Зачем:** Почтовый сервер требует авторизацию. Обычно это полный email‑адрес ящика, с которого будут отправляться письма.

**Примеры:**
- `smartword@yandex.ru`
- `noreply@mydomain.com` (если настроена почта на своём домене)

---

### SMTP_PASS
**Что это:** Пароль для SMTP‑сервера.

**Зачем:** Подтверждение личности при подключении. Для безопасности почти все провайдеры требуют **пароль приложения** (app password), а не обычный пароль от почты.

**Важно:** Никогда не коммитьте `.env` в git. Пароль должен быть только в локальном `.env`.

---

### MAIL_FROM
**Что это:** Адрес отправителя, который видит пользователь в письме (поле «От кого»).

**Зачем:** Определяет, от чьего имени приходит письмо. Пользователь видит именно этот адрес.

**Правила:**
- Обычно совпадает с `SMTP_USER` (Яндекс, Mail.ru так требуют).
- Если у вас свой домен (например `smartword.app`), можно указать `noreply@smartword.app` — но тогда этот адрес должен быть привязан к вашему ящику в настройках провайдера (алиас или основная почта).

**Примеры:**
- `smartword@yandex.ru` — если ящик `smartword@yandex.ru`
- `noreply@smartword.app` — если настроена почта на домене `smartword.app`

---

## Пример заполнения .env

### Вариант 1: Яндекс (бесплатно)

1. Создайте почту на [yandex.ru](https://mail.yandex.ru) (например `smartword@yandex.ru`).
2. Настройки → Пароли и безопасность → Пароли приложений → Создать пароль.
3. Скопируйте сгенерированный пароль.

```env
SMTP_HOST=smtp.yandex.ru
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=smartword@yandex.ru
SMTP_PASS=ваш_пароль_приложения_из_яндекса
MAIL_FROM=smartword@yandex.ru
```

---

### Вариант 2: Mail.ru (бесплатно)

1. Создайте почту на [mail.ru](https://mail.ru).
2. Настройки → Пароль и безопасность → Пароли для внешних приложений → Добавить.
3. Скопируйте пароль.

```env
SMTP_HOST=smtp.mail.ru
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=smartword@mail.ru
SMTP_PASS=ваш_пароль_приложения
MAIL_FROM=smartword@mail.ru
```

---

### Вариант 3: Gmail

1. Включите двухфакторную аутентификацию в Google‑аккаунте.
2. Настройки Google → Безопасность → Пароли приложений → Создать.
3. Используйте сгенерированный пароль.

```env
SMTP_HOST=smtp.gmail.com
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=your.email@gmail.com
SMTP_PASS=пароль_приложения_16_символов
MAIL_FROM=your.email@gmail.com
```

## Кастомный email‑адрес сервиса (noreply@smartword.app)

### Как обычно выглядит

Типичные адреса для сервисов:
- `noreply@smartword.app` — для автоматических писем (верификация, сброс пароля)
- `support@smartword.app` — для поддержки
- `hello@smartword.app` — общий контакт

Формат: `имя@ваш-домен.ru` или `имя@ваш-домен.com`.

### Как получить такой адрес

Нужны две вещи: **домен** и **почтовый хостинг**.

#### Шаг 1: Домен

Купите домен (например `smartword.app`) у регистратора (Reg.ru, Timeweb, Cloudflare, Namecheap и т.п.).

#### Шаг 2: Почтовый хостинг на своём домене

Варианты:

| Провайдер | Условия | Что даёт |
|-----------|---------|----------|
| **Yandex 360 для бизнеса** | Платно, есть бесплатный тариф | `noreply@smartword.app` и SMTP |
| **Mail.ru для домена** | Есть бесплатные тарифы | Почта на своём домене |
| **Zoho Mail** | Бесплатно до 5 пользователей | `имя@smartword.app` |
| **Cloudflare Email Routing** | Бесплатно | Только пересылка на другой ящик, не полноценная отправка |
| **Google Workspace** | Платно | `noreply@smartword.app` через Gmail |

#### Шаг 3: Настройка DNS

Провайдер почты выдаст MX‑записи. Их нужно добавить в настройках домена у регистратора. Пример для Yandex:

```
MX  smartword.app  10  mx.yandex.ru
```

#### Шаг 4: Создание ящика и пароля приложения

Создайте ящик `noreply@smartword.app` (или `smartword@smartword.app`) в панели провайдера. Создайте пароль приложения для SMTP.

#### Шаг 5: Заполнение .env

```env
SMTP_HOST=smtp.yandex.ru
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=noreply@smartword.app
SMTP_PASS=пароль_приложения
MAIL_FROM=noreply@smartword.app
```

(Для Yandex 360 SMTP‑сервер тот же — `smtp.yandex.ru`.)

## Быстрый старт без своего домена

Если домена пока нет:

1. Создайте бесплатную почту на Яндексе: `smartword.app@gmail.com` или `smartword.serv@yandex.ru`.
2. Включите пароль приложения.
3. Заполните `.env` по примеру для Яндекса выше.
4. Письма будут приходить с адреса `smartword.serv@yandex.ru` — для разработки и первых пользователей этого достаточно.

Позже можно перейти на `noreply@smartword.app`, когда будет настроена почта на домене.

---

## Проверка

После заполнения `.env` перезапустите сервер и зарегистрируйте тестового пользователя. Письмо должно прийти на указанный email. Если письма нет — проверьте папку «Спам» и логи сервера на наличие ошибок SMTP.
