# Тестирование после миграции с Supabase

## Подготовка

### Бэкенд

1. **PostgreSQL** должен быть запущен (у вас: `localhost:9999`, БД `smartword`).
2. В `backend/.env` заданы:
   - `DATABASE_URL` — строка подключения к Postgres
   - `PORT` (по умолчанию 3000)
   - `JWT_SECRET`, `JWT_REFRESH_SECRET`
   - `OPENROUTER_API_KEY` — для AI-чата (перевод, подсказка, диалог)

3. Применить схему и запустить сервер:

```bash
cd backend
npx prisma generate
npx prisma db push
node src/server.js
```

### Мобильное приложение

1. В `app/.env` указан URL бэкенда:
   ```
   EXPO_PUBLIC_API_URL=http://localhost:3000
   ```
   Для теста на физическом устройстве в той же сети используйте IP ПК вместо `localhost`, например: `http://192.168.1.100:3000`.

2. Запуск приложения:
   ```bash
   cd app
   npm start
   ```

## Автоматическая проверка API (бэкенд)

При запущенном сервере (порт 3000):

```powershell
cd backend
./scripts/test-api.ps1
```

Скрипт проверяет: health, регистрацию, логин (через токен), профиль, группы (GET/POST), слова (GET/POST), статистику.

## Ручные сценарии в приложении

1. **Регистрация и вход**
   - Открыть приложение → экран входа → «Зарегистрироваться».
   - Ввести email и пароль (≥ 6 символов) → после успеха должен открыться главный экран с табами.

2. **Профиль**
   - Вкладка «Профиль»: отображаются email, аватар, ник.
   - Настройки → «Изменить пароль»: ввести текущий и новый пароль → сохранение через API.

3. **Словари и слова**
   - Вкладка «Группы»: создать группу (название, язык) → открыть группу → добавить слова (оригинал + перевод).
   - Редактирование и удаление группы/слова.

4. **Статистика**
   - Вкладка «Профиль» (или экран статистики): проверка отображения «всего слов», «выучено», streak, активность за неделю.

5. **Чат с ИИ**
   - Вкладка «Чат» → «Начать практику» → выбрать группу или свободный режим → отправить сообщение.
   - Проверить ответ бота, кнопки «Перевод» и «Подсказка» у сообщений с иностранным текстом.
   - При исчерпании лимита сообщений — сообщение о лимите (без падения).

6. **Выход**
   - Профиль → «Выйти из аккаунта» → после подтверждения переход на экран приветствия/входа.

## Деплой (кратко)

- Разместить бэкенд на любой платформе (Railway, Render, Fly.io, VPS).
- Задать переменные: `DATABASE_URL`, `JWT_SECRET`, `JWT_REFRESH_SECRET`, `OPENROUTER_API_KEY`, при необходимости `PORT`.
- Выполнить на сервере: `npx prisma db push` или `prisma migrate deploy` (если используете миграции).
- В приложении для продакшена задать `EXPO_PUBLIC_API_URL` на URL развёрнутого API.
