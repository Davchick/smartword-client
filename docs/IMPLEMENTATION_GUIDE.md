### Шаг 3. Добавление согласия при регистрации

```javascript
// client/src/screens/Auth/SignInScreen.tsx или RegisterScreen

const [acceptedTerms, setAcceptedTerms] = useState(false);
const [acceptedPrivacy, setAcceptedPrivacy] = useState(false);

// В форме регистрации:
<Checkbox
  value={acceptedTerms}
  onValueChange={setAcceptedTerms}
  label="Я принимаю условия Пользовательского соглашения"
/>

<Checkbox
  value={acceptedPrivacy}
  onValueChange={setAcceptedPrivacy}
  label="Я принимаю условия Политики конфиденциальности"
/>

// Перед отправкой формы:
if (!acceptedTerms || !acceptedPrivacy) {
  Toast.show('Необходимо принять условия соглашения и политики');
  return;
}
```

**⚠️ Важно:** Галочки **НЕ ДОЛЖНЫ** быть проставлены по умолчанию (требование GDPR и лучших практик).

### Шаг 4. Публикация в магазинах приложений

#### App Store Connect

1. Перейдите в App Store Connect → Ваше приложение
2. Раздел **App Privacy**
3. Добавьте ссылку на Политику конфиденциальности (URL)
4. Заполните **Data Types** (категории данных):
   - Contact Info (email)
   - User Content (слова, сообщения)
   - Identifiers (user ID)
   - Usage Data (статистика)
   - Diagnostics (логи)
5. Укажите **Data Used to Track You** (если применимо)
6. Укажите **Data Linked to You**

#### Google Play Console

1. Перейдите в Google Play Console → Ваше приложение
2. Раздел **Policy and programs** → **Data safety**
3. Заполните анкету:
   - Какие данные собираются
   - Как используются
   - Передаются ли третьим лицам (ДА — ИИ, платежи)
   - Можно ли удалить данные (ДА)
4. Добавьте ссылку на Политику конфиденциальности

### Шаг 5. Уведомление Роскомнадзора

**⚠️ Обязательно по 152-ФЗ!**

1. Перейдите на сайт Роскомнадзора: https://rkn.gov.ru/
2. Форма уведомления: https://rkn.gov.ru/personal-data/register/
3. Заполните форму:
   - ФИО ИП, ИНН, ОГРНИП
   - Цель обработки ПДн
   - Категории данных
   - Категории субъектов
   - Перечень действий с данными
   - Сведения о локализации (БД в РФ)
   - Сведения о трансграничной передаче (США — OpenRouter)
4. Отправьте уведомление
5. Дождитесь включения в реестр операторов ПДн

**Срок:** До начала обработки ПДн (фактически — до запуска приложения).
