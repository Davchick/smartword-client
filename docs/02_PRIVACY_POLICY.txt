- Дата и время создания Аккаунта — для учёта и статистики;
- Статус верификации email — для подтверждения учётной записи.

3.1.2. Данные Google OAuth (при входе через Google)
- Google ID (субъект) — уникальный идентификатор аккаунта Google;
- Адрес электронной почты Google — для идентификации;
- Имя и фамилия — для персонализации;
- Ссылка на аватар (Google Picture) — для отображения в профиле;
- Статус верификации email Google — для подтверждения.

3.1.3. Данные об обучении
- Словари (группы слов) — названия, языки, даты создания;
- Слова — оригинал, перевод, дата добавления;
- Прогресс обучения — количество правильных ответов, дата последнего повторения;
- Статус слов — активные, в архиве (выученные);
- Статистика тренировок — очки, даты занятий.

3.1.4. Данные об использовании ИИ-функций
- Текстовые запросы к ИИ — сообщения в AI-чате, запросы на перевод, запросы подсказок;
- Контекст диалога — история сообщений в чате;
- Слова из словаря Пользователя — передаются как контекст для генерации ответов ИИ;
- Счётчик использованных ИИ-сообщений — для контроля лимитов;
- Настройки ИИ-функций — выбранный язык общения, предпочтения.

3.1.5. Платёжные данные
- Статус подписки — бесплатный / Premium;
- Дата окончания подписки — для контроля доступа;
- История платежей — дата, сумма, статус (обрабатывается платёжными системами);

- IP-адрес — для безопасности и аналитики;
- Информация об устройстве — модель, ОС, версия Приложения;
- Идентификаторы устройства — для push-уведомлений;
- Журналы событий — для отладки и безопасности;
- Язык интерфейса — для локализации;
- Часовой пояс — для корректного отображения времени.

3.1.7. Данные поддержки
- Текст обращений в поддержку — для обработки запросов;
- История переписки — для контроля качества;
- Контактные данные для связи — email, Telegram (при предоставлении).

6. СПОСОБЫ И СРОКИ ОБРАБОТКИ

6.1. Способы обработки

6.1.1. Обработка персональных данных осуществляется:

- сбор;
- запись;
- систематизация;
- накопление;
- хранение;
- уточнение (обновление, изменение);
- извлечение;
- использование;
- передача;
- обезличивание;
- блокирование;
- удаление;
- уничтожение.

6.2.1. Оператор обеспечивает локализацию баз данных с персональными данными граждан РФ на территории Российской Федерации в соответствии с требованиями ч. 5 ст. 18 152-ФЗ.

6.2.2. Первичный сбор, запись, систематизация, накопление, хранение, уточнение и извлечение ПДн осуществляются с использованием баз данных, расположенных на территории РФ.

6.2.3. Трансграничная передача (раздел 5.2.3) осуществляется после локализации и только в целях, указанных в настоящей Политике.

6.3. Сроки обработки

6.3.1. Персональные данные обрабатываются в течение срока действия Пользовательского соглашения.

6.3.2. После удаления Аккаунта Пользователя:
- данные удаляются в срок до 30 (тридцати) дней;
- [ТРЕБУЕТ УТОЧНЕНИЯ] отдельные данные могут храниться дольше в соответствии с требованиями законодательства (например, данные о платежах — 5 лет для налогового учёта).

6.3.3. Срок хранения данных о платежах:
- 5 (пять) лет — в соответствии с требованиями налогового законодательства РФ;
- хранятся в обезличенном виде после истечения срока.

6.3.4. Срок хранения журналов событий и логов:
- до 1 (одного) года — для целей безопасности и отладки;
- после истечения срока — удаляются или обезличиваются.

6.3.5. При отзыве согласия на обработку ПДн:
- обработка прекращается в срок до 15 (пятнадцати) рабочих дней;
- данные удаляются в срок до 30 (тридцати) дней, если иное не требуется по закону.

6.4. Уничтожение данных

6.4.1. Уничтожение персональных данных осуществляется:
- по достижении целей обработки;
- при отзыве согласия;
- при выявлении неправомерной обработки;
- по требованию субъекта или уполномоченного органа.

6.4.2. Уничтожение осуществляется путём:

7. ПРАВА СУБЪЕКТА ПЕРСОНАЛЬНЫХ ДАННЫХ

7.1. Права Пользователя

В соответствии с гл. 3 152-ФЗ, Пользователь имеет следующие права:

7.1.1. Право на доступ (ст. 14 152-ФЗ)
Пользователь вправе получить информацию:
- о наличии обработки его ПДн;
- о целях и правовых основаниях обработки;
- о способах обработки;
- о сроках обработки;
- о перечне обрабатываемых ПДн;
- об источниках получения ПДн;
- о лицах, которым могут быть переданы ПДн.

7.1.2. Право на уточнение (ст. 14 152-ФЗ)
Пользователь вправе требовать:
- уточнения своих ПДн;
- исправления неточных или неполных данных;
- обновления данных.

7.1.3. Право на блокирование (ст. 14 152-ФЗ)
Пользователь вправе требовать блокирования ПДн в случаях:
- выявления неправомерной обработки;
- недостоверности данных;
- отзыва согласия (на период проверки).

7.1.4. Право на удаление (ст. 14 152-ФЗ, ст. 17 152-ФЗ)
Пользователь вправе требовать удаления своих ПДн в случаях:
- достижения целей обработки;
- отзыва согласия;
- выявления неправомерной обработки;
- истечения срока хранения.

7.1.5. Право на отзыв согласия (ч. 2 ст. 9 152-ФЗ)
Пользователь вправе отозвать согласие на обработку ПДн в любой момент.

7.1.6. Право на обжалование (ст. 17 152-ФЗ)
Пользователь вправе обжаловать действия Оператора:
- в Роскомнадзор;
- в суд;
- в иные уполномоченные органы.

7.2. Порядок реализации прав

7.2.1. Для реализации прав Пользователь может:
- использовать функции Приложения (просмотр, редактирование, удаление данных);
- направить запрос по электронной почте [EMAIL ДЛЯ ПДН];
- направить письменное заявление по почтовому адресу [ПОЧТОВЫЙ АДРЕС ДЛЯ ПДН].

7.2.2. Запрос должен содержать:
- ФИО Пользователя;
- контактные данные (email, телефон);
- суть запроса;
- дату и подпись (для письменного запроса).

7.2.3. Срок рассмотрения запроса:
- до 30 (тридцати) дней с момента получения;
- в отдельных случаях срок может быть продлён ещё на 30 дней с уведомлением Пользователя.

7.2.4. Ответ направляется:
- по электронной почте (при наличии согласия);
- почтовым отправлением;
- через Приложение.

7.3. Ограничения прав

7.3.1. Реализация прав может быть ограничена в случаях, предусмотренных ч. 8 ст. 14 152-ФЗ:
- угроза обороне и безопасности государства;
- предотвращение преступлений;
- защита прав и законных интересов третьих лиц;
- иные случаи, предусмотренные законом.
